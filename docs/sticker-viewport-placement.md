# 长图贴图出现在当前可见区域

在纵向或横向长图中添加贴纸、导入装饰图或添加几何形状时，新对象的中心取自当前可见画布。滚动到哪里就添加到哪里，画布放大后也能直接看到并拖动。

以前这些对象使用整张画布的中心 `(0.5, 0.5)`，长图的中间部分可能远离正在浏览的区域。

编辑会话现在在添加对象时向当前画布查询位置。画布将滚动视图可用区域转换为未缩放的画布坐标，扣除导航、工具面板等安全区，并与画布范围相交。位置查询使用弱视图引用，不订阅滚动来修改工程，不额外写入草稿或撤销历史。

新位置仅应用于本次添加。已经放好的贴图、重新打开草稿、撤销和重做继续使用保存的位置。其他拼图模式保留原有的默认位置。画布还未建立或查询失效时回退到有效的画布中心。

## 验证

- 核心：每次读取最新可见位置、已放对象保持位置、撤销重做和草稿编解码、导入装饰图和形状、其他模式默认位置、不可用位置的回退。
- 模拟器：长图顶部添加后立即拖动；纵向长图滚动并放大到 144% 后连续添加；横向长图滚动并放大后添加；对象中心与独立计算的屏幕画布区域比较。
