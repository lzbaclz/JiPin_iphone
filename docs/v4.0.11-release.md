# 极拼 4.0.11（构建 15）

通用“一寸”模板不是所有报名网站的固定规格。本版把按网站要求自定义的入口移到通用模板前，支持精确像素、名称和文件大小上限。

## 使用

证件照 → 按网站要求自定义 → 填写宽度、高度及可选名称、文件上限 → 使用 → 导入照片或继续编辑 → 保存。

- 快捷项填写：名称“报名一寸”、285×385 px、文件小于 1000 KB，并开启“保留原背景并关闭轻修”。
- 可自行命名为“自定义一寸”“二寸报名照”等；名称不改变输出规则。自定义宽高在高清／压缩两档中均严格保持输入像素。
- 1 KB 按 1000 字节计算，快捷 1 MB 严格限制为小于 1,000,000 字节，也低于截图中 1024 KB 的上限。
- 仅在设定上限且文件超限时降低 JPEG 压缩质量；只渲染一次图像，不通过缩小像素满足限制。最低质量仍超限时明确失败，保留编辑内容。
- 保存页显示实际字节数和文件上限；原有保存成功后自动关闭、系统分享和存储到文件继续可用。
- 名称、像素、文件上限和原背景选择随草稿保留；换照片建立新草稿时沿用规格与上限。原片、蒙版及旧草稿兼容性保持。
- 自定义照片在编辑页、导出页和草稿列表显示像素，避免用毫米推测网站提交要求。文件名中的路径字符与过长文本会安全处理。
- 表单提供“完成输入”键盘按钮和固定错误提示，避免键盘挡住文件上限或错误说明。

## 原片要求

截图同时要求白底、近期、免冠且不得修饰。应从符合要求的未修饰原片开始；选择“保留原背景并关闭轻修”会关闭换底、亮度／磨皮／色温和修边笔画，保留尺寸和构图调整。不能通过关闭本应用的轻修还原一张在其他软件中已经修饰过的照片，也不保证报名或证书审核通过。

本版输出 JPG，属于截图接受的格式；没有向该报名网站上传用户照片。

## 验证

- 46 个不同单元用例通过（基础 20、渲染 19、会话 7）。新测试覆盖自定义名称和上限的草稿恢复、旧草稿缺省值、非法字段、285×385 两档输出与小于 1 MB、严格“小于”边界、超小上限明确失败、换照片沿用要求。
- 7 个不同 UI 用例通过：主页、原自定义尺寸校验、保存收尾、两档像素、统一草稿箱恢复，以及网站快捷规格／名称与上限输入。首轮发现键盘阻挡输入下方选项，补充完成输入操作后专项回归通过。
- 快捷项界面用例实际读取生成 JPG，确认两档均为 285×385、字节数低于 1,000,000，并检查原背景开关和三个轻修参数为 0。测试插画只验证功能，不作为真实报名照片或合规验收材料。
