# 极拼 4.0.5（构建 9）

修复 Live 预览完成后更改时长，画面退回空白占位且不再自动生成的问题。主 App 与扩展统一为 4.0.5 / 9，最低 iOS 17，草稿 schema 保持 4。

## 修复行为

- 更改 1.5 / 2 / 3 秒、声音或清晰度后，自动生成最新设置对应的预览。
- 预览生成期间仍可修改动态设置，短时间连续更改会合并请求；正式保存和分享的生成阶段继续锁定设置。
- 取消旧任务后等待其清理完成，再启动替代任务。旧任务不能覆盖新预览、进度、错误消息或忙碌状态。
- 关闭窗口会取消未完成请求，重新打开可以正常预览；从静态导出或分享返回时按需要恢复预览。
- 原生播放器切换资源时停止旧播放并重新播放新资源；辅助功能显示实际编码的预览时长。
- 保存和视频分享继续按项目所选的 1080 / 1440 清晰度生成正式文件，保存成功后返回编辑器。

## 根因与实现

原来的 `invalidate()` 只清空 `result` 和 `live`。自动生成仅放在 `onAppear`，因此同一个窗口内更改时间不会再次触发，画面停在“留住会动的回忆”。

现在以时长、音源和清晰度组成的配置驱动刷新。每次请求有独立标识，250 毫秒合并连续变化，并等待前一次任务结束。导出锁由真正获得它的任务负责释放；取消界面请求不会提前释放仍在使用的导出锁。成功结果还要匹配当前项目和配置才可显示或保存。
