# JiPin 4.0.8（构建 12）

将证件照工具与首页重复选择拼图模式的修复合并为同一个 TestFlight 版本。

## 使用流程

- 首页已选择自由拼图或长图拼接时，选完照片直接进入对应编辑器。
- 首页已选择模板拼图或海报拼图时，只继续选择该模式的布局或海报，不再显示四种模式的重复选择。
- 首页通用「选择照片」入口仍保留模式预览。取消后重选不会沿用旧照片或旧模式；照片数量不足时明确提示，不擅自切换模式。
- 系统选图窗口完全关闭后再进入后续界面，保留导入取消、部分成功及 Live 数量限制。
- 新增独立证件照入口，支持五个常用规格、自定义像素、五色换底、自然轻修、手动修边与独立草稿；完整功能和验证边界见 [证件照记录](v4.0.8-id-photo.md)。

## 整合与验证

- 基于 4.0.7 的 `77cc7ac`，整合模式入口修复 `0918224` 与证件照实现 `6068a3e`；最终业务代码合并提交为 `9ae6a9d`。
- 合并后在独立 iPhone 17 / iOS 26.3.1 模拟器执行 10 项 UI 测试，全部通过。包括 6 项新模式入口用例、2 项证件照交互用例，以及通用照片入口和海报预览的既有回归。
- 模式入口用例实际操作系统 PhotosPicker，覆盖自由、长图、模板和海报入口，通用选图、取消重选和照片不足。已人工检查导出测试截图中的直接编辑页及模板选择页。
- 证件照开发阶段另完成 192 个不同单元用例（190 通过、2 个既有图库读取专项跳过）与 10 项 UI；本轮整合测试与其中部分重合，未相加为不同用例总数。原生 Mac Vision 的 51 张实图验证和真机尚未完成的边界见证件照记录。
