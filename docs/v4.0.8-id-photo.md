# 极拼 4.0.8 · 证件照

新增独立的证件照制作入口。选择尺寸并导入一张照片后，可在本机识别人像、切换底色、轻修和手动修边，再按明确的像素尺寸保存。

## 本次功能

- 五个常用规格：25×35、35×49、22×32、35×45、33×48 mm；默认 300 ppi，分别输出 295×413、413×579、260×378、413×531、390×567 px。
- 自定义每边 100–2048 px，总像素不超过 400 万。
- 白、红、蓝、蓝白渐变、浅灰五种底色；支持保留原背景。
- 亮度、轻磨皮、色温全部默认 0。「自然」配方主动开启，提供对比原图和复位。
- 提亮采用保持黑白端点的有界中间调曲线，避免简单曝光增益造成额头高光过曝。磨皮限定在保守面部区域，保护五官和衣服。
- 人像识别只在导入／主动重试时执行。切色复用蒙版，连续手势用串行合并预览，避免尾部防抖导致移动时画面停住。
- 手动裁切与发丝／衣领修边；双指检查缩放不改变最终构图；最多 50 步撤销／重做。
- 高质量 JPEG、精确像素、300 ppi、sRGB、去定位信息。相册确认成功后关闭导出窗口；失败说明和其他保存方式保持可见。
- 独立证件照草稿目录，保存失败保留旧草稿，损坏蒙版可显式恢复。原有拼图草稿及共享素材回收规则不变。

## 使用边界

- 这是照片制作工具，不提供官方认证、回执或审核通过保证。正式用途请按办理方要求选择尺寸、底色及是否允许修改。
- 只处理单人静态照片；Live 导入只使用静态照片。
- 复杂背景、发丝及与衣服相近的颜色可能需要人工修边。缺失的头发、模糊的五官不会被生成式补全。
- 系统人像分割在当前 iOS 模拟器会返回 `E5RT is not supported`；应用显示真实失败并允许保留原底调整尺寸，不伪造换底成功。算法实图验证使用本机原生 Vision，模拟器的显式蒙版 fixture 仅验证 UI／几何／编码流程。
- 本轮只发布 TestFlight；App Store 正式版本的审核状态单独维护。

- 对照原片人工复核五官、耳朵、卷发、眼镜与轻修最大值；复杂旗帜背景在少数衣领旁被系统识别为人物，需手工擦除。输入以公开肖像为主，不将本轮称为已完成规划中 20/20/10 的完整分层样本验收，也不对外宣称自动抠图成功率。
