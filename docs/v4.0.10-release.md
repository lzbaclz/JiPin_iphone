# 极拼 4.0.10（构建 14）

修复证件照编辑页一直显示标准版像素／300 ppi 的问题，并解释一寸、二寸预览相近的原因。

## 变更

- 编辑页输出提示与保存页使用同一个导出配置：显示清晰度、实际像素和 ppi。选择尺寸、切换高清／压缩、撤销和恢复草稿都会更新。
- 尺寸卡片按当前清晰度显示实际像素；新建入口默认显示高清像素。证件照草稿列表用毫米规格说明尺寸，避免将模板标准像素误解为高清输出。
- 像素不足提示也按所选导出尺寸及实际工作原片尺寸计算，与保存页同步。
- 新建入口和编辑器的尺寸面板都提供「尺寸对比」。一寸 25×35 mm、二寸 35×49 mm 按同一比例绘制并列示意；说明两者长宽比均为 5:7，屏幕预览会适配容器，打印尺寸有区别。
- 示意图明确说明不代表屏幕上的实际厘米数，并列出五个固定模板的毫米规格；不会为了制造视觉差别修改人像裁切。

## 边界

本轮修复显示与说明。模板数据、高清／压缩的编码参数、实际像素、ppi、裁切和人物处理算法保持原有结果。自定义像素继续严格按用户输入输出，尺寸对比示意不替代具体办理方要求。

## 验证与发布

- 41 项证件照单元测试通过，覆盖原有模板、编码、蒙版、草稿与编辑会话。
- 7 项不同 UI 用例通过：五模板与自定义尺寸、保存成功收尾、高清／压缩像素、统一草稿箱重开、编辑页实际输出同步、尺寸对比普通／大字体、原首页四模式。最终两项新交互专项再次通过，未重复计数。
- 输出同步用例实际检查二寸 JPEG 为 1652×2316／1200 ppi；切压缩后编辑页显示 413×579／300 ppi，撤销与重做均同步。自定义 601×801 在两档间保持像素与 300 ppi。
- 从新建入口和编辑器均可打开尺寸对比。普通及辅助功能大字体下，实际界面测量两个图框的宽高比约 1.4，底部对齐；图框可滚动查看、没有被文字覆盖。说明文字调整到图后，先显示尺寸关系。
- 已人工查看正常与大字体的对比页，以及最终编辑页提示截图。未将模拟器验证称为新增真机验收。
