# 极拼 4.0.2（构建 6）

这一版根据实际模拟器体验，调整从选图、编辑到保存的完整流程。最低系统仍为 iOS 17，草稿 schema 保持 4。

## 选图后先看效果

- 模式选择默认展开，使用本次选入的照片展示完整成品预览。
- 模板、自由、海报、长图可以直接切换；模板按少裁切推荐排序，布局和海报候选也显示真实照片。
- “开始”固定在底部；需要挑选部分照片时显示缩略图及已选数量。
- 首页优先展示主选图入口和四种模式，示例入口收为次级操作。
- 专门的 Live 入口只显示 Live，最多选择 9 张；普通入口仍支持混拼，模式选择会检查动态来源上限。

## 编辑与保存

- “更多”菜单显示“复制到其他模式”“图层列表”的完整文字。
- 增加“全部工具”入口，能直接找到横向工具栏后方的功能。
- 调整页先展示旋转、翻转和构图微调；图层与透明度收进展开区，照片管理独立分组。
- 文字字号显示占画布短边的比例，行距显示倍数，滑杆都有可读名称；移除重复键盘工具条。
- 风格面板直接提供实图预览和一键套用，“全部·我的风格”保留收藏与管理功能；保存个人风格后自动定位到新卡片并显示成功反馈。
- 普通导出固定显示“保存到相册”，自动生成所需文件；保存状态也固定显示。分享、文件存储和单独生成仍可从列表使用。

## Live 首次体验与输出

- 两份原创示例预渲染为 720×960、3 秒的原生 Live 配对资源，约 1.6 MB，随 Swift Package 打包。
- 加载示例直接读取本地素材，为每次作品分配新的照片标识，动态文件通过 lease 保持有效。
- 示例进度使用本地准备文案，不再显示 0/2 的云端照片下载提示；取消后不打开编辑器。
- 动态预览先合成最长边 640 的预览；保存和视频分享另行准备用户选定的 1080 / 1440 成品。预览文件不会作为正式保存或分享结果。
- 已完成缩小、方向为正的视频使用直接轨道解码，避免重复的视频合成。全量回归中发现的大图解码等待已通过该路径修复，九路动态和旋转素材分别验证。

## 原创 Live 资源维护

成对资源位于 `Packages/JiPinCore/Sources/JiPinCore/Resources/LiveSamples/`，绘制定义为 `LivePhotoSamples.renderPair`。

需要重新生成时，在开发工作区暂时移出 `sample-0/1.jpg/mov`，仅构建模拟器 App；清除该模拟器 App 自己的 `Library/Caches/JiPin-Live-Samples-v1` 后，以 `-sampleLiveEditor` 启动。开发回退路径将完整配对资源原子写入该缓存目录。将各 `sample-N/still.jpg`、`sample-N/motion.mov` 复制回资源目录，分别命名为 `sample-N.jpg`、`sample-N.mov`，再重新构建。

最后运行 `LivePhotoTests/testReadyMadeSamplesKeepFreshIdentityAndNativeMotion`。该测试要求从安装包读取资源，并通过苹果原生 Live 解析、时长、独立标识、取消和 GPS 检查。不要将仅有静态 JPEG 的文件当作完整示例发布。

真机速度、iCloud 下载、真实照片 App 扩展宿主和低内存设备仍需要真机验证；模拟器测试不替代这些场景。
