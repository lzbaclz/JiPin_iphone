# 极拼 4.0.9（构建 13）

修复证件照成品像素偏小、主草稿箱看不到证件照的问题，增加默认高清、可选压缩的导出方式。

## 行为

- 高清从保留的原片重新渲染，固定模板宽高均为标准版的 4 倍，JPEG 质量 0.98。不是将已压缩的小照片放大，也没有新增强锐化或磨皮。
- 压缩版保留模板的标准像素，JPEG 质量 0.80，便于有尺寸要求的提交。
- 一寸照：高清 1180×1652 px／1200 ppi，压缩 295×413 px／300 ppi。像素和 ppi 同比例增加，保留原有构图和名义打印尺寸；其他固定模板同理。
- 自定义像素不随清晰度改变，两档均保持输入宽高，仅改变 JPEG 压缩质量。导出显示实际像素与文件大小，不保证通用 KB 上限。
- 新建和旧版没有清晰度字段的草稿默认高清；手动选压缩后记住该项目的选择。切换时清除旧字节，生成完成前禁止保存／分享，避免标签已切高清却保存旧压缩文件。
- 首页「草稿」新增证件照分组，可直接继续编辑和删除；原有 4.0.8 草稿直接读取，原片、蒙版、修边与轻修参数保留。证件照工具内仍能查看这些同一份草稿。
- 打开导出前先完成草稿写入，失败留在编辑器并说明原因。相册确认保存成功后仍自动关闭导出页。

## 边界

高清不会修复原片已经模糊或缺失的细节。人像源解码保持现有 4096 长边／约 838 万像素上限，高清输出亦有大小保护。裁切放大导致可用像素不足时会提示。正式证件用途仍以办理方要求为准。

本版不修改正在审核的 App Store 正式版本。

## 验证

- 41 项证件照单元测试通过：18 项模型／存储、17 项渲染、6 项会话。新增细线图样验证高清保留原始高频细节，压缩小图无法保留这些细节；同时验证两档元数据、自定义尺寸和旧草稿默认值。
- 5 项证件照 UI 通过：自定义像素与相册保存收尾、高清／压缩切换及真实输出像素、保存后从统一草稿箱重开并跨进程恢复、修边／裁切／撤销恢复、拒绝相册权限保留导出和替代入口。
- 原有首页四模式、模板导出、预选自由模式直达编辑器 3 项 UI 回归通过。
- 首轮界面测试发现新增说明将滚动区里的保存按钮挤出可见区域；现已改为底部固定按钮，修正后相关保存和权限用例通过。
- 原生 Mac Vision 使用此前授权的 3 张肖像（含卷发和眼镜）重新验证高清和压缩输出。15 次五底色高清 JPEG 元数据检查及 3 次压缩输出检查均通过，0 处理错误；人工查看了高清人像、导出页和统一草稿页。示例蓝底文件：高清约 258–392 KB，压缩约 24–43 KB；不是对所有照片的大小保证。
- 不将本轮 Mac／模拟器结果称为手机端完整验收。输入照片自身清晰度仍限制最终细节。

本地证据保留于 Git 忽略的 `build/IDPhoto409/`：`Unit.xcresult`、`UI.xcresult`（首轮含问题发现及三项旧功能通过记录）、`UIFixed.xcresult`、`UIRecovery.xcresult`、`MacResults/` 与 `UIReview/`。
