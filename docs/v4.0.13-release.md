# 极拼 4.0.13（构建 17）— 单张长图

2026-09-18 用户确认继续发布。代码修改完成，5 项核心测试和 8 项 UI 测试通过，签名归档与 IPA 校验通过，已上传 Apple 并完成处理；内部测试已开放，公开外测等待 Apple 审核。

## 问题与修改

原长图排版引擎已能处理单张照片，但 `PhotoLimits` 将长图范围设置为 2–20，导致首页入口、通用模式选择及编辑器删除保护不允许单张。

- 共用范围改为 1–20；首页和编辑器从同一规则显示数量。
- 通用选图的一张照片现在可选长图模式，说明文字同步更新。
- 可由多张删除至一张，仍禁止删至空白项目；原有添加照片、撤销、草稿和导出流程保持。
- 相册快捷扩展改为 1–9 张。单张默认进入长图，不提供不适用的模板选择；零张仍禁用保存。部分照片导入失败时，剩余一张仍需确认，不能静默忽略失败照片。
- App 内帮助和 README 同步数量说明。主 App 与扩展的版本源已改为 4.0.13（17）。

使用：主页点“长图拼接”后只选一张，或通用“选择照片”选一张再选长图，即可继续裁切、编辑、导出和保存草稿。相册分享扩展选择单张时直接进入长图。
